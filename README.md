# Ma liste de tâches

Un petit programme en Python pour noter les tâches à faire. Il permet d’ajouter une tâche, de l’afficher, de la marquer comme terminée ou de la supprimer.

Les tâches sont sauvegardées dans un fichier nommé taches.json, créé automatiquement à côté du programme.

## Lancer le programme

Python 3 doit être installé. Ouvre un terminal dans ce dossier et lance :

python main.py

Le menu propose cinq choix. Entre le numéro de l’action que tu veux faire.

## Ce que ce projet permet de pratiquer

- les fonctions et les boucles;
- les listes et les dictionnaires;
- la lecture et l’écriture d’un fichier JSON;
- la vérification des réponses saisies.
