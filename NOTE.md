# Note sur le projet

Ce projet est un petit gestionnaire de tâches écrit en Python. Il permet d’ajouter des tâches, d’afficher la liste, de marquer une tâche comme terminée et de la supprimer. Les tâches sont conservées dans le fichier `taches.json`, créé automatiquement à côté du programme.

Pour l’utiliser, il faut Python 3. Ouvre un terminal dans le dossier du projet et lance `python main.py`.

J’ai réalisé ce projet pour pratiquer les fonctions, les boucles, les listes, les dictionnaires et la lecture et l’écriture de fichiers JSON.
